# Cache Simulator Using C++

## About the Project

A menu-driven C++ project that simulates cache memory and demonstrates different cache mapping techniques.

## Features

* Direct Mapping
* Fully Associative Mapping (FIFO)
* Fully Associative Mapping (LRU)
* Set Associative Mapping (LRU)
* Cache Hit and Miss Detection
* Cache Status Display
* Performance Statistics

## Technologies Used

* C++
* G++ Compiler
* GitHub Codespaces

## How to Run

**Compile:**

```bash
g++ main.cpp -o cache_simulator
```

**Run:**

```bash
./cache_simulator
```

## Concepts Covered

* Cache Memory Organization
* Cache Mapping Techniques
* Memory Address Breakdown
* FIFO and LRU Replacement Policies
* Cache Performance Analysis
